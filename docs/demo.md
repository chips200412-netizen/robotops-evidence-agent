# 三分钟认识 RobotOps

本页结合可运行的离线命令和历史真实界面截图讲解工程设计。截图于 **2026-09-30** 在本地合成预览中采集，三个状态彼此独立；没有连接真实机器人、模型、MySQL 或真实业务资料。录制说明条属于展示注释，不是产品功能。

## 实际运行离线入口

已有 Python 3.12 时，在仓库根目录执行：

```bash
python -S -B -m examples.offline_safety_demo
python -S -B -m unittest discover -s tests -v
```

可以看到风险合并、人工接管、失败关闭、非法值拒绝和预算耗尽的五组结果，以及 13 个测试。无需 key、模型、数据库或第三方依赖。这里运行的是确定性逻辑，不启动下述网页，不生成真实模型回答。
